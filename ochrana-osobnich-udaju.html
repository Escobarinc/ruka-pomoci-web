Jaké údaje web zpracovává

Web nepoužívá cookies, analytické ani reklamní nástroje a neobsahuje žádné formuláře. Při prohlížení webu od vás nesbíráme žádné osobní údaje.

Web je provozován na hostingu GitHub Pages (GitHub, Inc.). Poskytovatel hostingu může z technických a bezpečnostních důvodů zaznamenávat IP adresy návštěvníků. Více informací najdete v prohlášení GitHub o ochraně osobních údajů.

Pokud nás kontaktujete

Pokud nám napíšete (například do datové schránky), zpracujeme údaje, které nám sami poskytnete, pouze za účelem vyřízení vašeho dotazu. Právním základem je náš oprávněný zájem odpovědět vám. Údaje uchováváme jen po dobu nezbytnou k vyřízení komunikace.

Dary

Web zatím dary nepřijímá. Po spuštění sbírky tyto zásady doplníme o informace o zpracování údajů dárců.

Vaše práva

V souvislosti se zpracováním osobních údajů máte právo:

  • na přístup ke svým osobním údajům,
  • na jejich opravu nebo výmaz,
  • na omezení zpracování,
  • vznést námitku proti zpracování,
  • na přenositelnost údajů,
  • podat stížnost u Úřadu pro ochranu osobních údajů (uoou.gov.cz).

Svá práva můžete uplatnit u správce na výše uvedené adrese nebo prostřednictvím datové schránky.
